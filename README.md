# 촬영용 화면 소품

모큐멘터리 촬영에 쓰는 노트북·휴대폰 화면을 웹페이지로 만든 저장소입니다.
등장하는 공모전·기관·언론사·인물 이름은 모두 허구입니다.

| 폴더 | 씬 | 기기 | 내용 |
|---|---|---|---|
| `contest/` | S#2 | 맥북 | 공모전 사이트 '모아콘' — 청소년 미술 공모전 목록, 대상 45만 / 90만 / 180만 원 상세, 즐겨찾기 |
| `portal/` | S#3 | 휴대폰 | 네이버 스타일 포털 — '지다람' 검색 → 뉴스 기사 → 댓글 13개 |

## 실행

맥북에서 저장소 폴더로 이동해 간단한 서버를 켭니다.

```bash
python3 -m http.server 8000     # 또는: npx serve -l 8000
```

- 맥북: http://localhost:8000 → 소품 목록 페이지
- 휴대폰 (같은 와이파이): `http://<맥북 IP>:8000/portal/` — 맥북 IP는 시스템 설정 → Wi-Fi → 세부사항에서 확인

> **주소창 주의.** `localhost`나 `192.168…` 주소가 화면에 잡히면 가짜인 티가 납니다.
> 클로즈업이 있다면 Netlify / Vercel / Cloudflare Pages 같은 무료 호스팅에 올려 그럴듯한 주소로 쓰는 것을 추천합니다
> (폴더를 그대로 끌어다 놓으면 배포됨).

## S#2 공모전 사이트 (`contest/`)

- 바로가기: `contest/index.html?cat=art` (미술/회화 분야가 선택된 목록)
- 시나리오 속 공모전: id 1 = 대상 45만 원, id 2 = 90만 원, id 3 = 180만 원 (주제 '현대사회 속 인간성의 회복')
- 상세는 별도 페이지(`detail.html?id=N`)라 **트랙패드 두 손가락 스와이프 '뒤로 가기'** 가 그대로 동작하고, 목록의 필터와 스크롤 위치도 유지됩니다
- 즐겨찾기는 브라우저에 저장됩니다. 테이크를 다시 갈 때는 즐겨찾기를 한 번 더 눌러 해제하세요
- 데이터: `contest/assets/data.js`. 날짜는 '오늘 기준 일수'라서 언제 촬영해도 D-day가 자연스럽습니다
- 포스터: `contest/assets/posters.js` — 미술 공모전 전용 디자인과 분야별 벡터 포스터. 상세에서 ‘포스터 크게보기’로 확대할 수 있습니다. [디자인·참고 자료](docs/포스터_디자인.md)

## S#3 포털 (`portal/`)

- 흐름: 홈 → 검색창에 아무 검색어(예: 지다람) → 첫 번째 뉴스 → 기사 하단 '댓글' → 댓글 목록
- 기사·댓글 문구: `portal/assets/data.js`. 로고 글자는 같은 파일의 `brand` 값을 바꾸면 됩니다
- 기사 사진: 다람의 실제 그림 사진을 `portal/img/`에 넣고 `ARTICLE.image`에 경로를 적으면 교체됩니다
- 댓글은 시나리오 순서 그대로이고, 맨 위 두 개가 칭찬 댓글이라 캡처 후 아래쪽을 잘라내면 칭찬만 남습니다
- 기사 입력 시각과 댓글 시각은 '지금으로부터 n분 전'으로 계산됩니다
