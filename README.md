# 모아콘 (MOACON) — 모큐멘터리 촬영용 가짜 공모전 사이트

공모전 플랫폼(올포영, 위비티 등)의 레이아웃을 참고해 만든 **촬영 소품용 정적 사이트**입니다.
게시된 공모전 · 기관 · 회사명은 모두 허구입니다.

## 실행
빌드 없음. `index.html` 을 브라우저로 열면 됩니다.
(또는 `python3 -m http.server` 후 http://localhost:8000)

## 촬영 때 쓸 만한 기능
- 분야 아이콘 클릭 → 카테고리 필터
- 좌측 상세검색(대상/주최사/시상규모/혜택) 칩 토글
- 정렬 탭(최신 · 마감임박 · 조회 · 상금), 카드형/리스트형 전환
- 카드 클릭 → 상세 모달(포스터, 시상내역, 지원하기/스크랩/공유)
- 스크랩(북마크) 버튼, 우측 상단 북마크 아이콘으로 스크랩 목록 보기
- 검색창 실시간 검색, 배너 자동 슬라이드, D-day 뱃지(임박 시 빨간색 깜빡임)
- `index.html#contest-1` 처럼 주소로 특정 공모전 상세를 바로 띄울 수 있음

## 데이터 수정
`assets/data.js` 의 `CONTESTS` 배열을 고치면 됩니다.
`start` / `end` 는 **오늘 기준 일수**라서 언제 촬영해도 D-day가 자연스럽게 나옵니다.
(예: `end: 0` → D-Day, `end: 3` → D-3, 음수 → 마감)
